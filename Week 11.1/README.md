# Week 11.1 — Portfolio Gallery Component

A Create React App project for the Web Programming Week 11.1 homework.

## Requirements covered

- Reusable `ProjectCard` component with title, description, technology stack, GitHub link, and demo link.
- `ProjectList` component rendering four project cards from an array.
- `FilterBar` component with working ALL, REACT, NODE, and CSS filters.
- Responsive layout with keyboard-visible focus styles.

## Run locally

This project was created with Create React App.

```bash
cd "Week 11.1"
npm install
npm start
```

Open http://localhost:3000 in your browser.

To create a production build:

```bash
npm run build
```
